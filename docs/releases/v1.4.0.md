# Zanger v1.4.0

Review Git changes before merging, search within the current file, and adjust the workspace to fit your terminal.

## Git review

- Press `g` to choose a target from local and remote-tracking branches. Review the current branch's committed changes since its common ancestor with the target, equivalent to `git diff target...HEAD`.
- Browse changed files with status labels for additions, modifications, deletions, renames, untracked files, and existing merge conflicts. Unified diffs show colored additions and deletions, old/new line numbers, and change counts.
- Press `w` for combined staged and unstaged changes against HEAD, plus untracked files. Use `b` to choose another target, `r` to refresh, and `n` / `N` to navigate diff hunks.
- Git runs in background workers. Review supports nested repository directories, linked worktrees, detached HEAD, initial files before the first commit, binary-change notices, and filenames containing spaces or Unicode.
- Returning to the explorer preserves the selected file, search queries, and preview position.

Git must be installed and available on PATH. Branch review uses committed changes and excludes local edits, which are available in the working-tree view. It does not perform a merge or predict conflicts, and remote-tracking branches reflect the last fetch performed outside Zanger. Large displayed diffs are capped at 20,000 lines or 2 MiB and marked as partial.

## Search and preview

- Press `Space` twice consecutively to open filename search in a centered popup with live results, a result count, and arrow-key selection.
- Press `/` to find text inside the current file preview. Matches highlight as you type without changing workspace filters or file selection. Use `Up` / `Down` to navigate matching lines, then `Enter` or `Esc` to close search; `n` / `N` continues match navigation.
- Press `?` to search content across workspace files using the search popup.
- Press `Ctrl+P` to toggle full file or diff preview, including opening the selected file search result. Returning from full preview preserves the scroll position.
- Search input supports literal spaces and Unicode queries. Help returns to the active search without discarding its query.

## Pane sizing and controls

- `Alt+Left` shrinks the focused pane and `Alt+Right` widens it by four columns in the explorer and Git review. Use `Tab` to switch focus.
- Both panes retain a minimum width of 24 columns. The selected split survives temporary terminal resizing and full-preview toggles during the session.
- The F1 guide, command-line help, contextual hints, and README describe the new controls.

### Shortcut changes from v1.3.0

| Action | v1.4.0 shortcut |
|--------|----------------|
| Search filenames | `Space` then `Space` (previously `/`) |
| Find text in the current file | `/` |
| Search content across files | `?` |
| Expand or collapse a folder | `Enter` (`Space` is now reserved for search) |
| Full file or diff preview | `Ctrl+P` |
| Resize the focused pane | `Alt+Left` / `Alt+Right` |
| Open Git review | `g` |
