# Zanger v1.5.0

Find TODOs across your workspace, filter them by path or text, and jump straight to the matching source line. Todo Explorer shows results as they arrive and keeps your original browsing position when you return.

## Todo Explorer

- Press `T` (`Shift+T`) in normal mode to open Todo Explorer. Each result shows the relative file path, line number, and matching source text.
- Select a result to preview its file at the matching line with your selected syntax theme. Use `f` to filter results by path or text, `/` to search within the preview, and `n` / `N` to move between TODOs or active preview-search matches.
- Press `r` to rescan after external edits, including newly created or deleted files. Refresh retains the filter and selected path/line when it still exists.
- Use `Tab` to switch panes, `Ctrl+P` for full file preview, and `Alt+Left` / `Alt+Right` to resize the focused pane. Narrow terminals show the focused pane alone.
- Press `Esc` to close input or full preview first, then return to browsing. Returning preserves the original file selection, workspace filters, folder folds, and preview position.
- The F1 guide, CLI help, contextual hints, and README document the new controls.

Matching is case-insensitive and uses whole-word `TODO` markers, including `TODO:`, `TODO(owner)`, and `todo`. Each matching source line appears once. Comments, strings, and documentation are all searched. Scanning respects `.gitignore` and `.ignore`, includes non-ignored hidden files, excludes `.git` metadata, and skips symlinks. Binary files, non-UTF-8 files, and files larger than 10 MiB are skipped, with counts and scan errors shown in the status bar.

## Faster scanning and live progress

- Up to four background workers scan files concurrently and reuse read buffers. Whole-file matching quickly rejects files without TODOs; binary reads stop at the first NUL-containing chunk.
- Results and file counts appear during scanning. New batches preserve your selection, preview query, and scroll position once you start navigating.
- Leaving Todo Explorer cancels the scan. Refresh replaces the previous request, and results from an older scan cannot overwrite the new results.
- Local Windows release-build measurements on a workspace with 3,512 text files improved from approximately 340–390 ms with the initial sequential scanner to 65–95 ms. Both found the same 25 TODO lines and skipped 63 files. These measurements compare development implementations of Todo Explorer; scanning is new in v1.5.0. Timings vary with hardware, filesystem caching, and workspace contents.

## Validation

- 37 automated tests cover TODO detection, ignore rules, source line numbers, binary handling, streaming, cancellation, refresh, keyboard navigation, preview preservation, and existing explorer/Git features.
- Two optional manual benchmarks measure scanner and Todo Explorer opening performance.
- Clippy passes with warnings treated as errors, and formatting checks pass for changed Rust files.
- Windows GNU release build verified locally. The release workflow builds Windows, Linux, and macOS packages for x86_64 and ARM64.
