# Zanger v1.6.0

Start with a compact folder tree, choose side-by-side or stacked panes, and review the last Codex turn directly in a terminal popup.

## Collapsed folders and flexible panes

- Folders now start collapsed, including after refreshing the tree. Opening a folder reveals its immediate children without expanding its subfolders. Three-level prefetching remains available for responsive navigation.
- Press `Ctrl+W`, release, then `v` for a vertical split (files left, preview right), or `s` for a horizontal split (files above, preview below).
- Both layouts work in the file explorer, Git review, Codex turn changes, and Todo Explorer. Each view retains separate width and height preferences while open. Switching layouts preserves selection and preview position.
- `Tab` switches focus. `Ctrl+W` then `h`/`l` or `k`/`j` focuses the first/second pane. `Ctrl+P` toggles full preview.
- `Alt+Left/Right` shrinks/grows the focused pane by four columns or two rows, depending on layout. `Alt+Up/Down` also resizes stacked panes. Small terminals show only the focused pane when both cannot fit; the selected split is restored when space returns.
- Paging uses the visible height of the focused pane. Split shortcuts apply in normal mode and preserve existing search, branch-picker, and filter input behavior.

## Codex terminal popup and last-turn changes

- Run `zanger --codex [PATH]` and press `Alt+Z` to open a floating Zanger pane inside the same terminal. Requires Codex CLI and Zellij on PATH; no skill invocation is needed.
- The popup opens on recorded file changes from the last finished Codex turn, with colored patches, line numbers, and addition/deletion counts. It refreshes on opening and after completion notifications. Replies with no recorded edits show an empty state.
- `Esc` returns to file browsing, `F2` restores last-turn changes, and `q` or `Alt+Z` returns to Codex. `b` opens Git review for all local or branch changes.
- Recorded patches remain reviewable after commits or file deletion. Failed/declined patches are excluded. Multiple edits to one file appear in edit order; shell edits or separate agent-thread edits may lack recorded patches. Use **Working tree** in Git review for all local changes.
- Before the first completion notification, history is labeled **Latest saved session** for the workspace. An explicit resume UUID binds immediately; subsequent notifications select the attached session and turn. Resume with `zanger --codex PATH -- resume --last`.
- Session-local configuration preserves any existing notification command. An optional MCP package provides read-only file, search, preview, and Git tools, independently of the popup.

## Workspace search and Vim navigation

- Lazy loading fetches three levels at a time. Double-Space fuzzy search covers all workspace files and folders, including unloaded branches. Append `/` to search folders only; select a folder to reveal it. Ignore rules apply.
- Normal mode supports `gg`/`G`, `h`/`j`/`k`/`l`, `za`/`zo`/`zc`, `zR`/`zM`, and Ctrl+U/D/B/F paging. Git review uses `gb` to avoid conflicts with Vim prefixes.
- The F1 guide, CLI help, and README describe all controls.

## Validation

- Automated tests cover collapsed startup and explicit expansion, both split directions, resizing bounds, small terminals, focused paging, input conflicts, selection preservation, Codex recorded patches, and existing search/Todo/Git behavior.
- Formatting and Clippy checks run locally, along with a Windows GNU release build. The tag workflow builds Windows, Linux, and macOS packages for x86_64 and ARM64.
